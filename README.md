# tbiondi-genomics

Computational genome projects by Thomas Biondi, done by Claude Fable 5.2 and Claude Opus 5.5 agents and checked by AI,
not reviewed by a human; no lab work.

## Projects

- [grigorovia-mito-insertions](grigorovia-mito-insertions/): A census of 20,343 mitochondrial genomes for
  codon-skipping lineages; nothing new under frozen rules, plus one exploratory yeast candidate (*Grigorovia
  jiainica*).
